# Website Designs

This repository contains a collection of simple website design projects created for practice and learning purposes.

Inside this repo, you will find different basic website layouts and designs built using front-end technologies such as:

- HTML
- CSS
- JavaScript

These projects represent simple concepts and experiments in web design, including responsive layouts, landing pages, and user interface ideas.

## Purpose

The goal of this repository is to:

- Practice front-end development skills
- Improve website design techniques
- Store past projects and experiments
- Showcase learning progress over time

## Note

Some projects were created earlier during the learning journey, so code structure and design styles may vary.
